# Корпоративна база знань · ТехноСервіс

Локальна демоверсія для передзахисту кваліфікаційної роботи «Розробка та впровадження хмарного прикладного сервісу управління корпоративними знаннями та технічною документацією».

## Запуск у VS Code

1. Розпакуй архів. У VS Code вибери **File → Open Folder** і відкрий папку `knowledge-base`.
2. Відкрий **Terminal → New Terminal** і виконай:

   ~~~powershell
   python server.py --open
   ~~~

   Якщо на Windows доступна команда `py`, можна виконати `py -3 server.py --open`. Також можна двічі клацнути `start-demo.cmd` у Провіднику.
3. Відкрий [http://127.0.0.1:8000](http://127.0.0.1:8000), якщо браузер не відкрився автоматично. Сервер працює, доки відкритий термінал. Зупинка — **Ctrl+C**.

Потрібен Python **3.11 або новіший**. Додаткові пакети й інтернет для запуску не потрібні. Якщо порт 8000 зайнятий, виконай `python server.py --port 8080 --open`.

## Демонстраційні облікові записи

| Роль | Пошта | Пароль |
|---|---|---|
| Редактор | `editor@demo.test` | `Demo2026!` |
| Читач | `reader@demo.test` | `Demo2026!` |
| Адміністратор | `admin@demo.test` | `Demo2026!` |

Кнопки ролей на сторінці входу заповнюють демодані. Натисни **Увійти** для перевірки пароля сервером.

## Сценарій показу на 3–4 хвилини

1. Увійди як **Редактор**. Знайди `ПРИНТЕР` і відкрий «Налаштування принтера». Покажи, що пошук працює незалежно від регістру.
2. Повернися до списку та натисни **Створити інструкцію**. Назви її «Перевірка пробного друку», вибери «Обладнання», введи кроки й збережи. Онови сторінку, щоб показати збережений запис.
3. Відкрий нову інструкцію, зміни один рядок через **Редагувати** і відкрий **Історія версій**. Покажи попередню редакцію.
4. Вийди. Увійди як **Читач**, знайди нову інструкцію і відкрий її. У читача доступні перегляд, пошук і повідомлення про неточність. Створення та редагування сервер дозволяє редактору й адміністратору.
5. За наявності часу надішли повідомлення як читач і покажи його в розділі **Неточності** від імені редактора.

Робочий сценарій для доповіді: «Редактор створює й оновлює технічну інструкцію. Працівник знаходить її за ключовим словом. Сервер перевіряє роль, перш ніж зберегти зміни».

## Код і дані

- `server.py` — локальний HTTP-сервер, REST API, сеанси та перевірка прав.
- `database.py` — схема SQLite, збереження історії та демонстраційні записи.
- `public/` — український вебінтерфейс на HTML, CSS та JavaScript.
- `test_api.py` — перевірки HTTP API з тимчасовою базою даних. Запуск із папки проєкту: `python -m unittest -v`.

Під час першого запуску створюється `data/knowledge.sqlite3`. У ній зберігаються всі зміни. Для перенесення вже змінених даних на інший ПК зупини сервер і скопіюй папку `data` разом із кодом.

Python, SQLite і браузерний JavaScript обрано для локальної демонстрації. Сервер приймає запити лише з цього ПК, а облікові записи призначені для демонстрації. Хмарне розгортання та пілот із працівниками — окремі етапи кваліфікаційної роботи.
